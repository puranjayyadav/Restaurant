# Assets Directory

## Plandit Logo

Place your Plandit logo image here as `plandit_logo.png`.

**Recommended specifications:**
- Format: PNG (with transparency if needed)
- Size: 512x512px or larger (square format works best)
- The logo will be displayed at 120x120 pixels on the home screen

The logo should look good on a light/white background since it's displayed in a circular container with a light surface color.
