# Product Roadmap

1. [ ] **AI-Powered "Insider Intelligence" Pipeline** — Implement `generate_place_insights.py` using OpenRouter to transform raw reviews into structured metadata (Hooks, Insider Profiles, and Plandit Benchmarks) stored in Supabase. `[S]`

2. [ ] **Cross-Platform Deep Linking** — Add functional deep links to OpenTable,Resy and Google Maps for every location in the Plandit app to facilitate bookings and navigation. `[XS]`
3. [ ] **User-Generated Itineraries** — Allow users to manually create and save their own "My Best Day" itineraries alongside the AI-generated ones. `[M]`
5. [ ] **Real-time Availability Integration** — Integrate OpenTable/Resy APIs (where possible) to show real-time table availability directly within the itinerary solver flow. `[L]`
6. [ ] **Social Sharing Enhancements** — Generation of beautiful, "Instagram Story" ready images of itineraries with QR codes for easy sharing and discovery. `[M]`
7. [ ] **Multilingual Support** — Implement localization for the Flutter app and geocoding support for non-English source content (e.g., Japanese Lemon8 posts). `[L]`

> Notes
> - Order items by technical dependencies and product architecture
> - Each item should represent an end-to-end (frontend + backend) functional and testable feature
